プライバシーポリシー

Obsidinotion は作者本人だけが使う個人用ツールです。

取得する情報

Google アカウントでログインしたとき、YouTube Analytics API と YouTube Data API から、ログインしたチャンネルの推定収益とチャンネル名だけを読み取ります。動画やコメントの変更など、書き込みは一切しません。

使い方と保存場所

読み取った情報は、作者の家計簿に入金予定として記録するためだけに使い、作者のPCの中だけに保存します。外部のサーバーや第三者には送りません。

アクセスの取り消し

Google アカウントの「サードパーティのアプリとサービス」から、いつでもアクセスを取り消せます。
